# 作业5：多档位触摸调速呼吸灯

## 实验目的

结合 PWM 呼吸灯与触摸自锁开关逻辑，实现触摸切换速度档位的呼吸灯。

## 硬件连接

| 组件 | ESP32 引脚 |
|------|-----------|
| 触摸传感器 | T0 (GPIO4) |
| LED | GPIO2 (板载) |

## 核心知识点

1. **PWM 呼吸灯** — `ledcAttach` / `ledcWrite` 新版 API
2. **非阻塞定时** — 用 `millis()` 驱动呼吸节奏，不阻塞触摸检测
3. **档位状态机** — `speedGear` 变量在 1→2→3→1 间循环
4. **触摸冷却防抖** — 换档后 400ms 内忽略触摸，防误触发

## 档位说明

| 档位 | 效果 | delay | step |
|------|------|-------|------|
| 1 | 缓慢呼吸 | 10ms | 1 |
| 2 | 中速呼吸 | 5ms | 2 |
| 3 | 急促呼吸 | 2ms | 4 |

## 使用方法

1. 用 Arduino IDE 打开 `ex05.ino`
2. 选择开发板：`ESP32 Dev Module`
3. 上传后打开串口监视器（115200 波特率）
4. LED 开始缓慢呼吸，触摸 T0 引脚切换档位
5. 观察串口输出确认档位切换

## 预期效果

- LED 持续呼吸，触摸一次切换一个速度级别
- 三个档位呼吸节奏差异明显
- 换档后短暂冷却，手抖不会连跳多档
