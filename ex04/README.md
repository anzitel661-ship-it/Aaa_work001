# 作业4：基于触摸传感器的"自锁"开关

## 实验目的

在基础触摸实验（摸着亮、松开灭）的基础上，引入**状态变量**和**边缘检测**，实现触摸自锁开关：摸一下LED常亮，再摸一下LED熄灭。

## 硬件连接

| 组件 | ESP32 引脚 |
|------|-----------|
| 触摸传感器 | T0 (GPIO4) |
| LED | GPIO2 (板载) |

## 核心知识点

1. **布尔状态变量** (`bool ledState`) — 记录LED当前亮灭状态
2. **边缘检测** — 判断"上次未触摸 → 当前触摸"的下降沿瞬间
3. **软件防抖** — 连续多次采样确认，过滤手抖误触发

## 使用方法

1. 用 Arduino IDE 打开 `ex04.ino`
2. 选择开发板：`ESP32 Dev Module`
3. 上传程序后打开**串口监视器**（波特率 115200）
4. 观察未触摸/触摸时的读数差异，按需修改 `THRESHOLD` 阈值
5. 触摸 T0 引脚测试自锁效果

## 预期效果

- 摸一下 → LED 亮起并保持
- 再摸一下 → LED 熄灭
- 手抖不会误触发
