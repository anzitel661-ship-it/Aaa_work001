# 作业8：物联网安防报警器模拟实验

## 实验目的

结合触摸传感器与 Web 服务器，模拟安防报警系统：网页端布防后，触摸触发 LED 高频闪烁报警，报警自锁，仅网页撤防可解除。

## 硬件连接

| 组件 | ESP32 引脚 |
|------|-----------|
| 触摸传感器 | T0 (GPIO4) |
| LED | GPIO2 (板载) |

## 状态机

```
  DISARMED ──布防──→ ARMED ──触摸──→ ALARM
     ↑                ↑                 │
     └──撤防──────────┴──撤防───────────┘

DISARMED: 触摸无效，LED熄灭
ARMED:    等待触摸触发
ALARM:    LED高频闪烁（120ms周期），自锁保持
```

## Web 界面

- 状态指示灯：绿(撤防) / 黄(布防) / 红闪烁(报警)
- 布防/撤防按钮
- 每秒自动轮询状态，报警时页面自动同步

## 使用方法

1. 修改 WiFi 名称和密码
2. 上传后打开串口监视器查看 IP 地址
3. 浏览器访问该 IP，点击"布防"
4. 触摸 T0 引脚触发报警，LED 开始高频闪烁
5. 松开手，LED 持续闪烁（报警自锁）
6. 点击"撤防"按钮，LED 熄灭，系统重置

## 预期效果

- 未布防时触摸引脚无任何反应
- 布防后触摸 → LED 高频闪烁锁定报警，松手不停止
- 仅网页点击撤防才能解除报警
