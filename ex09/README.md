# 作业9：实时传感器Web仪表盘

## 实验目的

实现 IoT 双向通信中的数据采集（上报）方向：ESP32 实时提供触摸传感器模拟量，网页端 AJAX 轮询并动态显示，形成仪器仪表风格的数据监控面板。

## 硬件连接

| 组件 | ESP32 引脚 |
|------|-----------|
| 触摸传感器 | T0 (GPIO4) |

## 核心知识点

1. **数据上报** — ESP32 `/data` 接口返回 JSON `{"value": <touchRead>}`
2. **AJAX 轮询** — 网页端 `setInterval` + `fetch` 每 200ms 拉取一次
3. **实时可视化** — 大字数值 + 动态条形图 + 状态标签，根据数值自动变色

## 数据流

```
触摸引脚 ──touchRead()──> ESP32 ──/data (JSON)──> 浏览器 AJAX 轮询
                                                    │
                                          ┌─────────┼─────────┐
                                          │         │         │
                                       大字数值   条形图   状态标签
                                      (实时跳动)(动态宽度)(空闲/靠近/触摸)
```

## 使用方法

1. 修改 WiFi 名称和密码
2. 上传后打开串口监视器（115200），查看 ESP32 IP 地址
3. 手机/电脑浏览器访问该 IP
4. 观察仪表盘数值，手靠近/触摸 T0 引脚，数值实时变化

## 预期效果

- 网页中央大字数值 200ms 刷新，实时跳动
- 手逐渐靠近 → 数值变小，颜色从蓝→橙→红
- 手指触摸 → 数值降至最低，状态标签显示"已触摸"
- 手指离开 → 数值恢复，状态标签恢复"空闲"
