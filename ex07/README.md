# 作业7：Web网页端无极调光器

## 实验目的

结合 PWM 呼吸灯与 Web 服务器，通过手机/电脑浏览器上的滑动条实时调节 LED 亮度。

## 硬件连接

| 组件 | ESP32 引脚 |
|------|-----------|
| LED | GPIO2 (板载) |

## 核心知识点

1. **WiFi + WebServer** — ESP32 作为 HTTP 服务器提供网页服务
2. **HTML 滑动条** — `<input type="range" min="0" max="255">`
3. **JavaScript fetch()** — 监听滑动条 `oninput` 事件，实时 GET 请求发送数值
4. **PWM 调光** — `ledcWrite` 根据接收的数值 (0~255) 调节亮度

## 数据流

```
浏览器滑动条 ──oninput──> JS fetch('/set?value=128') ──GET──> ESP32
                                                              │
                                                         ledcWrite(128)
                                                              │
LED 亮度改变 ◄────────────────────────────────────────────────┘
```

## 使用方法

1. 修改代码中 WiFi 名称和密码
2. 用 Arduino IDE 打开 `ex07.ino`，选择 `ESP32 Dev Module`
3. 上传后打开串口监视器（115200），查看 ESP32 的 IP 地址
4. 手机/电脑浏览器访问该 IP 地址
5. 拖动滑动条，LED 亮度实时变化

## 预期效果

- 浏览器页面显示美观的滑动条，拖动时实时反馈数值
- LED 亮度随滑动条位置平滑变化（0 = 熄灭，255 = 最亮）
