# lab02 — LED 闪烁与 SOS 求救信号

## 实验目的

掌握 Arduino/ESP32 中 `delay()` 函数的基本用法，通过 LED 闪烁理解程序时序控制。

---

## 内容

### 基础闪烁（lab02.ino）

LED 以 0.5Hz 频率循环亮灭，每次状态切换间隔 1 秒，同时通过串口输出当前状态。

| 参数 | 值 |
|------|-----|
| 亮时间 | 1000ms |
| 灭时间 | 1000ms |
| 频率 | 0.5Hz |
| LED 引脚 | GPIO 2 |

### SOS 求救信号（lab02_sos/lab02_sos.ino）

基于摩尔斯电码规范实现 SOS 信号：S = 三短闪，O = 三长闪。

| 字母 | 亮时间 | 灭时间 | 次数 |
|------|--------|--------|------|
| S | 200ms | 200ms | 3 |
| O | 600ms | 200ms | 3 |

字母间隔 500ms，单词间隔 2000ms。

---

## 硬件

- 开发板：ESP32 Dev Module
- LED：板载 LED（GPIO 2）

## 串口

波特率 115200，可实时观察 LED 状态变化。
