# lab03 — PWM LED 呼吸灯

## 实验目的

掌握 ESP32 PWM（脉冲宽度调制）的使用，通过 `ledcAttach()` 和 `ledcWrite()` 实现 LED 呼吸灯效果。

---

## PWM 原理

PWM 通过调整占空比（一个周期内高电平占比）来控制 LED 亮度：

```
占空比 0%:   ____________________  完全熄灭
占空比 50%:  ██████████__________  半亮
占空比 100%: ████████████████████  最亮
```

本实验中占空比从 0 到 255 循环变化，LED 呈现平滑的"呼吸"效果。

---

## 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 频率 | 5000Hz | PWM 信号频率，高于人眼可察觉范围 |
| 分辨率 | 8 位 | 占空比范围 0~255 |
| 渐变步进 | ±1 | 每次变化 1 个单位 |
| 步进间隔 | 10ms | 每步延时，控制呼吸速度 |
| LED 引脚 | GPIO 2 | ESP32 板载 LED |

---

## API 说明

```cpp
ledcAttach(ledPin, freq, resolution);  // 绑定 LED 引脚到 PWM 通道
ledcWrite(ledPin, dutyCycle);          // 设置占空比 (0~255)
```

---

## 硬件

- 开发板：ESP32 Dev Module
- LED：板载 LED（GPIO 2）

## 串口

波特率 115200，每个呼吸周期结束时输出提示。
