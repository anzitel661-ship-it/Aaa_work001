# 作业6：警车双闪灯效（双通道PWM）

## 实验目的

使用两个独立 PWM 通道驱动两颗 LED，实现反相渐变闪烁——灯A变亮时灯B变暗，模拟警车双闪的柔和过渡效果。

## 硬件连接

| 组件 | ESP32 引脚 | 备注 |
|------|-----------|------|
| 灯A (红) | GPIO16 | 串联 220Ω 限流电阻 |
| 灯B (蓝) | GPIO17 | 串联 220Ω 限流电阻 |

## 核心知识点

1. **双通道 PWM** — `ledcAttach` 为两个引脚分别初始化独立 PWM
2. **反相关系** — 灯A占空比 `duty`，灯B占空比 `255 - duty`，此消彼长
3. **平滑渐变** — 每步 delay 10ms，256 级 × 10ms ≈ 2.5 秒半周期，过渡柔和

## 使用方法

1. 在面包板上按上表连接两颗 LED
2. 用 Arduino IDE 打开 `ex06.ino`，选择 `ESP32 Dev Module`
3. 上传后观察两颗 LED 交替渐变
4. 修改 `FADE_DELAY_MS` 可调整过渡速度

## 预期效果

- 灯A渐变亮起时，灯B同步渐变熄灭
- 灯A渐变熄灭时，灯B同步渐变亮起
- 周期循环，过渡非常柔和
